# my-projects

| project | what it is |

| [`closed-loop-fraud/`](closed-loop-fraud/) | Closed-loop credit card fraud detection under selection bias. A simulator where declines censor their own labels, strictly point-in-time velocity features with property-based leakage tests, and randomised exploration + propensity weighting to recover the recall a naive retraining loop throws away. |

The decision layer is worth 4.7× the decile heuristic; an F1-optimal threshold is worth −2,728 per 1,000 orders. |
| [`investment-tracker-ai/`](investment-tracker-ai/) | LLM-agent portfolio tracker: data ingestion, metrics, visualisation, and a tool-using agent over a holdings file. |
